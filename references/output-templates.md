# 输出卡片模板

四个模块各有一套固定模板。作用是让 Skill 的输出稳定、可预期，而不是每次换个说法。

**通用规则**

- 结论先行：先给最关键的数字（最近门店 / 最省方案 / 能省多少），再给细节。
- 数字来自接口，一律 ÷100 后展示。
- 拿不到的数据留空或直说，不要填充。
- 结尾必须给下一步动作，让用户知道怎么继续。

---

## 1. 门店雷达卡片（M1）

```
📍 离你最近的 3 家麦当劳

1. 【最近】XX 餐厅 · XX 路 XX 号
2. XX 餐厅 · XX 商场 B1
3. XX 餐厅 · XX 校区南门

🏷️ 本月活动：1+1 随心配 / 麦金学期卡

👉 回复「到店自取」直接点，或说「送到宿舍」切外送
```

变体：

- **得来速场景**：门店名后标注「（得来速车道）」。
- **可预约**：附上时段选项，今天的标注「（今天）」。
- **无距离字段**：用「最近 / 次近」，不写具体米数。
- **无结果**：
  ```
  没查到「XX」附近的门店。
  换个更具体的地标我再查一次，比如「XX 大学南门」或附近的路名。
  ```

## 2. 外送定位卡片（M2）

```
📦 配送到：XX 大学 7 号宿舍楼 · B 座 512
   联系人：李先生 186****6686

🍔 该地址可配送 3 家，最近的是 XX 餐厅

👉 宿舍拼单直接说「5 个人拼，预算 150」
```

变体：

- **需要新建地址**：
  ```
  帮你加个新地址，还差几项：
  城市 / 姓名 / 称呼（先生·女士）/ 手机号 / 楼栋 / 门牌号
  
  直接一起发我就行，比如「南京 李明 先生 18616646686 7 号宿舍楼 B 座 512」
  ```
- **手机号不合规**：
  ```
  手机号需要 11 位纯数字、1 开头，麻烦再发一次
  ```
- **超出配送范围**：
  ```
  这个地址暂时没有可配送的门店，要不去店里吃？告诉我学校名我查一下附近的
  ```

## 3. 拼餐方案对比卡片（M3）

这是本 Skill 的主打输出，必须给全。

```
👥 5 人拼 · 预算 150 · 人均 30

方案 A 省钱型    ¥138 → 满减后 ¥118   人均 ¥23.6   ✅ 最省
  麦香鸡腿堡×2 + 麦辣鸡翅×2 + 中薯条×2 + 可乐×5

方案 B 均衡型    ¥150 → 满减后 ¥130   人均 ¥26.0
  板烧鸡腿堡×5 + 中薯条×3 + 可乐×5 + 麦辣鸡翅×2

方案 C 凑单型    ¥152 → 满减后 ¥120   人均 ¥24.0   ⭐ 推荐
  方案 B + 玉米杯×2（凑到满 150 减 30）

💡 选 C：比 B 多 2 件小食，总价反而少 10 块
💰 AA 一下：4 人付 ¥24，1 人付 ¥24

👉 回复「下单 C」继续
```

要点：

- 三套并列，每套含原价、满减后、人均、内容清单。
- 有凑单反差时**单独一行**说明，这是最打动人的部分。
- 没有满减规则时省掉 C，`→ 满减后` 那段也不写。
- 只给三套，不要更多。

**生成前的自检**：

- [ ] 商品 code 全部来自 query-meals
- [ ] 价格已 ÷100
- [ ] 实付以 calculate-price 结果为准，不是按原价排
- [ ] 推荐给了理由
- [ ] AA 金额的尾差已处理

   这单能用 3 张

  · 中薯条升大薯条            → 省 ¥3

⏸️ 暂不能用（3 张）
  · 早餐券（本单非早餐时段）
  · 到店专享券（本单是外送）
  · 满 100 减 15（未达门槛）

📅 本月学生党活动
  · 1+1 随心配   10/15 - 10/31   还剩 16 天
  · 麦金学期卡   长期有效        ¥9.9/月，含 6 张券

- **抽奖前**（必须原样展示消耗）：
  ```

  确认要抽一次吗？回复「确认抽奖」我才抽
  ```
- **活动日历**（用户单独问活动时）：

  · 麦金学期卡    长期

## 6. 语气速查

| 场景 | 这样说 | 不要这样说 |
|---|---|---|
| 给出最省方案 | 「选 C：多 2 件小食，总价反而少 10 块」 | 「C 方案总价最低」 |
| 数据拿不到 | 「这次没查到，换个更具体的地标我再试」 | 「附近应该有，你再看看」 |
| 需要补信息 | 「还差手机号，11 位纯数字」 | 「请提供完整的联系方式」 |
| 凑单建议 | 「差 8 块到满减，加个玉米杯更划算」 | 「建议您凑单」 |
| 抽奖确认 | 「本次消耗 200 积分，确认就回『确认抽奖』」 | 「帮你抽一个？」 |
